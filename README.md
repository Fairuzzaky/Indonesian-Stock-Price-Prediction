📈 Stock Price Forecasting Using Sentiment Analysis & Macroeconomic Indicators

📌 Overview
This project focuses on predicting stock prices by integrating public sentiment analysis with macroeconomic indicators such as exchange rates and inflation. Stock markets are inherently volatile, influenced by various internal and external factors. Therefore, leveraging Artificial Intelligence (AI) provides a data-driven approach to minimize risks and maximize investment opportunities.

This study specifically analyzes Indonesian banking stocks, namely:
 - Bank BCA
 - Bank BRI
 - Bank Mandiri

🎯 Objective
The main objective of this project is:
 - To predict stock prices using deep learning models
 - To analyze the impact of public sentiment and macroeconomic indicators on stock price movements
 - To evaluate model performance under highly volatile economic conditions
   
📊 Dataset
The dataset used in this project consists of:
 - Bank BCA
 - Bank BRI
 - Bank Mandiri
 - Inflation rate
 - Currency Exchange rate
 - Social media comments from platform X related to the three banks (BRI, BCA, Mandiri)
   
🗓️ Time period:
 - Jan 2019 until Jan 2025

This period was specifically chosen because it represents three major phases:
- Pre-pandemic 
- Pandemic 
- Post-pandemic

This allows the model to learn patterns under highly dynamic and volatile conditions.

🧠 Models Used
The following deep learning models were implemented:
 - Long Short-Term Memory (LSTM)
 - Convolutional Neural Network (CNN)
 - Hybrid CNN-LSTM

all models have been proven their performance in predicting a value in previous research.

📈 Results

All models demonstrated strong predictive performance.
- The LSTM model achieved the best results
- LSTM has Mean Absolute Percentage Error (MAPE) of less than 2% Indicates high accuracy in capturing stock price movements
